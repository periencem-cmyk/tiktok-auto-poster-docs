Política de Privacidade

Este aplicativo armazena localmente, no computador do usuário, apenas os dados necessários para publicar vídeos na conta do TikTok conectada: token de acesso, nome de usuário e metadados dos vídeos (título, hashtags, status de publicação). Nenhum dado é compartilhado com terceiros ou enviado a servidores externos além da própria API do TikTok. O usuário pode revogar o acesso a qualquer momento pelas configurações da conta TikTok.
